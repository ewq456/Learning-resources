# 编码规范


## 01-编码规范


> 良好的编码规范让代码更易读、易维护。参考 Google C++ Style Guide。

---

## 📐 命名规范（匈牙利命名法）

### 作用域前缀

| 前缀 | 含义 | 示例 |
|:----:|------|------|
| `m_` | 类成员变量 | `m_count` |
| `sm_` | 静态成员变量 | `sm_instance` |
| `s_` | 静态变量 | `s_lock` |
| `g_` | 外部全局变量 | `g_config` |
| `sg_` | 静态全局变量 | `sg_logFile` |
| `gg_` | 共享数据段全局变量 | `gg_shmData` |

### 类型前缀

| 前缀 | 类型 | 示例 |
|:----:|------|------|
| `n` | 整型/位域 | `nCount` |
| `e` | 枚举型 | `eState` |
| `c` | 字符型 | `cFlag` |
| `b` | 布尔型 | `bReady` |
| `f` | 浮点型 | `fValue` |
| `p` | 指针/迭代器 | `pBuffer` |
| `pfn` | 函数指针 | `pfnCallback` |
| `g` | 数组 | `gaData` |
| `i` | 类实例 | `iSocket` |

## 📏 代码风格

### 缩进与空格
- 使用 4 空格缩进（不要用 Tab）
- 运算符两侧加空格：`a = b + c`
- 逗号后加空格：`foo(a, b, c)`

### 大括号
```cpp
// 推荐：K&R 风格
if (condition) {
    doSomething();
} else {
    doOther();
}
```

### 命名
- **类名**: PascalCase（`MyClass`）
- **函数名**: camelCase（`doSomething`）或 snake_case（`do_something`）
- **常量**: kPascalCase 或 ALL_CAPS（`kMaxSize` / `MAX_SIZE`）
- **宏**: ALL_CAPS（`#define MAX_BUFFER 1024`）

### 注释
```cpp
// 单行注释用于简短说明

/*
 * 多行注释用于详细说明
 * 描述函数的功能、参数、返回值
 */
```

## ⚠️ 常见不规范写法

```cpp
// ❌ 不好
int i,j,k;
if(a==b) c=d;

// ✅ 好
int i = 0;
int j = 0;
int k = 0;
if (a == b) {
    c = d;
}
```
