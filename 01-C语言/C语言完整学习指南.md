# C语言完整学习指南（嵌入式方向）


## 01-C语言完整指南


> C语言是嵌入式开发的基石，也是理解操作系统内核的必备语言。
> 本指南涵盖从基础语法到高级指针的所有核心知识点，按正确的学习顺序编排。

---

## 第一章：为什么要学C语言

C语言是几乎所有现代编程语言的"母语"：
- **操作系统内核**（Linux、Windows）都是用C写的
- **嵌入式开发**的主力语言
- 学会C语言后，C++、Java、Go等语言都很容易上手
- C语言让你理解计算机的底层工作原理（内存、指针）

### 从基础学起编程

编程的本质是**告诉计算机做什么**。学习编程的正确路径：

1. 先理解基本概念（变量、类型、控制流）
2. 多写代码，每个知识点至少练习3次
3. 逐步挑战更复杂的项目
4. C语言是理解计算机最好的语言，因为它最接近硬件

### 进制转换规则

**其他进制→十进制**：从最低位开始，每位乘以基数的(位数-1)次方，求和。

```
二进制 110010 = 0*2^0 + 1*2^1 + 0*2^2 + 0*2^3 + 1*2^4 + 1*2^5 = 50
八进制 0777 = 7*8^0 + 7*8^1 + 7*8^2 = 511
十六进制 0x9CA1 = 1*16^0 + 10*16^1 + 12*16^2 + 9*16^3 = 40097
```

**十进制→其他进制**：不断除以目标基数，余数倒序排列。

**二进制→八进制**：从右往左，每3位一组转换。
```
1010011 → 001 010 011 → 1 2 3 → 123(八进制)
```

**二进制→十六进制**：从右往左，每4位一组转换。
```
11101101 → 1110 1101 → E D → 0xED
```

### 原码、反码、补码

**计算机中以补码形式存储数据！**

- **原码**：最高位是符号位（0正1负），其余为数值绝对值
- **反码**：正数反码=原码；负数反码=符号位不变，其余取反
- **补码**：正数补码=原码；负数补码=反码+1

```
例：-2 (8位)
  原码: 1000 0010
  反码: 1111 1101
  补码: 1111 1110
```

**特殊值-128**：在8位二进制下，-128的补码人为定义为 `1000 0000`。

**补码→十进制**（负数）：最高位不动，其余位取反+1。
```
补码: 1111 1001 → 取反: 1000 0110 → +1: 1000 0111 = -7
```

## 第三章：常量和变量

### 变量

变量是内存中一块有名字的存储空间。声明变量的本质是**向内存申请空间**。

```c
int a;          // 声明一个整型变量
int b = 10;     // 声明并初始化
```

### 常量

常量是程序中不可改变的值：

```c
const int MAX = 100;           // const常量
#define PI 3.14159             // 宏定义常量
enum { RED, GREEN, BLUE };     // 枚举常量
```

### 变量命名规则（匈牙利命名法）

| 前缀 | 含义 | 示例 |
|:----:|------|------|
| `n` | 整型 | `nCount` |
| `c` | 字符型 | `cFlag` |
| `b` | 布尔型 | `bReady` |
| `f` | 浮点型 | `fValue` |
| `p` | 指针 | `pBuffer` |
| `g_` | 全局变量 | `g_config` |
| `s_` | 静态变量 | `s_lock` |

## 第四章：结构化程序设计

```c

switch (表达式) {
    case 值1: /* ... */ break;
```

```c

for (int i = 0; i < 10; i++) {
    // 循环体

while (条件) {

}

// do-while（至少执行一次）
do {
    // 循环体

```

## 第五章：数组

数组是**相同类型数据的连续内存块**。

```c
int arr[5] = {1, 2, 3, 4, 5};    // 一维数组
int arr2[3][4];                    // 二维数组（3行4列）
char str[] = "hello";              // 字符串本质是字符数组
```

**数组名是首元素地址**，是一个常量指针。

## 第六章：函数

函数是程序的基本模块单元。

```c
// 函数声明（函数原型）
int add(int a, int b);

// 函数定义
int add(int a, int b) {
    return a + b;
}

// 调用
int result = add(3, 5);
```

### 函数参数传递

C语言中参数传递只有**值传递**一种方式。要想在函数内修改外部变量，需要传指针：

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

## 第七章：指针（C语言的灵魂）⚠️

### 指针是什么

**指针就是内存地址**。指针变量存储的是另一个变量的地址。

```c
int a = 10;
int *p = &a;    // p指向a，p的值是a的地址
*p = 20;        // 通过指针修改a的值
// 此时 a = 20
```

### 指针与数组

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;        // p指向arr[0]
// arr[i] 等价于 *(arr + i) 等价于 p[i] 等价于 *(p + i)
```

### 二级指针

二级指针是指向指针的指针：

```c
int a = 10;
int *p = &a;      // 一级指针
int **pp = &p;    // 二级指针

**pp = 20;        // 修改a的值（两次解引用）
// 等价于 *(*pp) = 20
```

**二级指针常见应用场景**：
1. 函数内修改外部指针的值（如动态分配内存后返回）
2. 指针数组的操作
3. 二维数组的动态分配

### 三级指针

```c
int ***ppp;  // 三级指针，指向二级指针的指针
```

三级指针常见于多维动态内存分配和复杂数据结构。

### 指针与const

```c
const int *p;      // 指向常量的指针（不能通过p修改值）
int *const p;      // 常量指针（p不能指向别处）
const int *const p; // 两者都不能改
```

**记忆技巧**：const在`*`前面 → 指向的内容不可变；const在`*`后面 → 指针本身不可变。

## 第八章：结构体、共用体与动态内存

### 结构体 struct

```c
struct Student {
    char name[20];
    int age;
    float score;
};

struct Student stu1 = {"张三", 20, 95.5};
// 访问成员
stu1.age = 21;
```

### 结构体内存对齐

结构体成员在内存中不是紧密排列的，编译器会按照**对齐规则**在成员之间填充字节：

```c
struct A {
    char c;    // 1字节
    int i;     // 4字节
};
// sizeof(struct A) = 8，不是5！
// 因为int需要4字节对齐，char后面填充了3字节
```

**对齐规则**：每个成员的地址偏移量必须是其自身大小的整数倍（或其对齐模数的整数倍）。

可使用 `#pragma pack(n)` 设置对齐字节数。

### 共用体 union

```c
union Data {
    int i;
    float f;
    char str[20];
};
// 所有成员共享同一块内存，大小为最大成员的大小
```

### 动态内存分配

```c
// malloc：分配内存（不初始化）
int *p = (int*)malloc(sizeof(int) * 10);

// calloc：分配并初始化为0
int *p2 = (int*)calloc(10, sizeof(int));

// realloc：重新分配内存
p = (int*)realloc(p, sizeof(int) * 20);

// 释放内存（必须！）
free(p);
p = NULL;  // 防止野指针
```

### typedef 和 #define

```c
typedef unsigned int uint;     // 给类型起别名
#define MAX_SIZE 100           // 宏定义（文本替换）
```

**区别**：
- `typedef` 是类型别名，编译器处理
- `#define` 是文本替换，预处理器处理

## 第九章：字符串操作

### 字符串的本质

C语言中没有专门的字符串类型，字符串是**以'\0'结尾的字符数组**。

```c
char str1[] = "hello";          // 栈上分配，可修改
char *str2 = "hello";           // 指向常量区，不可修改！

// str1 和 str2 的关键区别：
// str1: 在栈上分配了6字节空间（含'\0'），内容可以修改
// str2: 指针指向只读数据段，修改会导致段错误
```

### 常用字符串函数

```c
#include <string.h>

size_t strlen(const char *s);           // 计算长度（不含'\0'）
int strcmp(const char *s1, const char *s2); // 比较两个字符串
char *strcpy(char *dst, const char *src);   // 拷贝
char *strcat(char *dst, const char *src);   // 拼接
char *strstr(const char *haystack, const char *needle); // 查找子串
```

### 手写 strcpy

```c
char *my_strcpy(char *dst, const char *src) {
    char *ret = dst;
    while (*dst++ = *src++);  // 拷贝到'\0'为止
    return ret;
}
```

### 手写 strstr

```c
char *my_strstr(const char *str, const char *substr) {
    if (*substr == '\0') return (char*)str;
    while (*str) {
        const char *s1 = str;
        const char *s2 = substr;
        while (*s1 && *s2 && *s1 == *s2) {
            s1++; s2++;
        }
        if (*s2 == '\0') return (char*)str;
        str++;
    }
    return NULL;
}
```

## 第十章：通用链表（UNIX内核风格）

Linux内核中的链表是一种经典的**侵入式链表**设计：

```c
// 链表节点（嵌入到数据结构中）
struct list_head {
    struct list_head *prev, *next;
};

// 使用示例
struct MyStruct {
    int data;
    struct list_head list;  // 链表节点嵌入
};

// 通过list_head获取包含它的结构体
// 使用 container_of 宏：
#define container_of(ptr, type, member) \
    ((type *)((char *)(ptr) - offsetof(type, member)))
```

**设计优势**：链表操作与数据类型无关，一套代码操作所有链表。

## 第十一章：C语言的不足

了解C语言的局限有助于写出更好的代码：

1. **没有边界检查**：数组越界不会报错，导致缓冲区溢出
2. **手动内存管理**：忘记free导致内存泄漏
3. **没有命名空间**：大型项目容易命名冲突
4. **没有面向对象**：没有封装、继承、多态
5. **字符串操作繁琐**：没有string类型
6. **错误处理原始**：通过返回值/errno，没有异常机制

**这就是C++诞生的原因**——C++在C基础上增加了面向对象、模板、异常、STL等。
