# 嵌入式开发综合指南


## 00-嵌入式开发指南


> 嵌入式开发涵盖 MCU、RTOS、Linux嵌入式等多个方向。
> 当前笔记主要涉及 STM32、全志H616、FreeRTOS/RT-Thread。

## 🎯 嵌入式技术栈

```
        ┌──────────────────────────┐
        │   应用层 (C/C++/Qt)       │
        ├──────────────────────────┤
        │   OS层 (Linux/FreeRTOS)   │
        ├──────────────────────────┤
        │   驱动层 (I2C/SPI/UART)   │
        ├──────────────────────────┤
        │   硬件层 (ARM/RISC-V)     │
        └──────────────────────────┘
```

### 主要阶段
1. **C语言夯实** → C高级编程
2. **STM32单片机** → 外设驱动开发
3. **Linux环境编程** → 文件/进程/线程/网络
4. **全志Linux系统** → 内核/驱动/BSP
5. **FreeRTOS/RT-Thread** → 实时操作系统
6. **项目实战** → FTP服务器/智能家居/视觉垃圾分类
