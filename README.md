## 🔥 完整学习路线（嵌入式 C/C++ 方向）

```
第0阶段：计算机基础（1周）
  ├─ 进制转换：二进制/八进制/十进制/十六进制互换
  ├─ 原码、反码、补码（计算机以补码存储！）
  ├─ 内存模型：栈、堆、BSS段、数据段、代码段
  └─ 编译链接：预处理→编译→汇编→链接

第1阶段：C语言入门（3-4周）
  ├─ 数据类型及运算符 → 常量和变量
  ├─ 结构化程序设计（if/switch/for/while）
  ├─ 数组 → 函数
  └─ 🔥 指针（C语言的灵魂！重点难点）

第2阶段：C语言进阶（2-3周）
  ├─ 结构体/共用体/动态内存分配(#define/typedef)
  ├─ 内存对齐规则
  ├─ 二级指针/三级指针的应用场景
  ├─ 字符串操作（strlen/strcmp/const）
  ├─ char* vs char[] 的本质区别
  └─ 手写 strcpy/strstr

第3阶段：Linux 基础（1-2周）
  ├─ Linux核心思想（一切皆文件）
  ├─ 常用命令（文件/进程/网络/系统/压缩）
  ├─ 文件属性与权限（chmod/chown/SUID/SGID/SBIT）
  ├─ 软链接/硬链接/重定向/find/grep
  └─ Vim基本操作

第4阶段：构建与调试工具（1周）
  ├─ Makefile → CMake
  ├─ GDB 调试器
  └─ Git 版本控制

第5阶段：数据结构与算法（4-5周）
  ├─ 线性表/链表 → 栈/队列
  ├─ 二叉树 → BST → 线索二叉树
  ├─ AVL树（4种旋转：LL/RR/LR/RL）
  ├─ 红黑树（5条性质+变色旋转）
  ├─ 堆（大堆/小堆）→ 堆排序
  ├─ 哈希表（除留余数法+链地址法）
  └─ 图（邻接矩阵/邻接表 + DFS/BFS）

第6阶段：C++ 面向对象（4-5周）
  ├─ 从C过渡到C++（命名空间/cin/cout/bool/引用）
  ├─ 类与对象 → 构造函数与析构函数
  ├─ 🔥 拷贝控制（深拷贝/浅拷贝/写时拷贝）
  ├─ const/static成员 → this指针 → 友元
  ├─ 运算符重载
  ├─ 🔥 继承（菱形继承→虚继承）
  └─ 🔥 多态（虚函数/vtable/纯虚函数/抽象类）

第7阶段：C++ 进阶（3-4周）
  ├─ 函数模板 → 类模板 → 模板特化
  ├─ 异常处理 → 四种类型转换
  ├─ 流类库与文件IO
  ├─ STL：vector/deque/list/set/map → 仿函数 → 算法
  ├─ C++11：auto/lambda/智能指针/移动语义/thread
  └─ 设计模式（23种，重点5种：单例/工厂/观察者/策略/适配器）

第8阶段：Boost 智能指针（1周）
  ├─ scoped_ptr/scoped_array（独占）
  ├─ shared_ptr/shared_array（共享引用计数）
  └─ weak_ptr/intrusive_ptr

第9阶段：Linux 系统编程（3-4周）
  ├─ 文件IO（open/read/write/lseek）
  ├─ 进程（fork/exec/wait/守护进程/僵尸/孤儿）
  ├─ 🔥 进程间通信：管道/信号/共享内存/消息队列/信号量
  ├─ 多线程（pthread/mutex/条件变量/读写锁）
  └─ 生产者-消费者模型

第10阶段：网络编程（2-3周）
  ├─ Socket基础（TCP/UDP编程模型）
  ├─ 🔥 IO多路复用：select → poll → epoll
  ├─ 并发模型：多进程 → 多线程 → 线程池
  └─ 项目：聊天室/HTTP服务器

第11阶段：项目实战（持续）
  ├─ 大数运算（运算符重载）
  ├─ 哈夫曼压缩（数据结构应用）
  ├─ 多进程/多线程/线程池聊天室（网络编程）
  └─ poll/epoll服务器

第12阶段：专项深入（按需）
  ├─ 嵌入式MCU（STM32/全志H616/FreeRTOS）
  ├─ Qt开发（含OpenHarmony交叉编译）
  ├─ 音视频开发（FFmpeg）
  └─ 数据库（MySQL C API）
```

## 📝 使用建议

1. **按阶段学习**：每个阶段是后续阶段的基础，不要跳步
2. **多写代码**：每个知识点至少写3个练习
3. **理解底层**：画出内存布局、跟踪调用栈、理解vtable
4. **项目驱动**：学完一个阶段就做对应的项目巩固
5. **面试准备**：面试题集中在第10领域，简历也在那里
