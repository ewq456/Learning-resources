## 第一部分：Makefile

### 核心语法

```makefile
目标: 依赖
	命令    # 命令前必须用Tab缩进
```

### 简单示例

```makefile
# 变量定义
CC = gcc
CFLAGS = -Wall -g
OBJS = main.o foo.o bar.o
TARGET = app

# 最终目标
$(TARGET): $(OBJS)
	$(CC) -o $@ $^

# 编译规则
%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# 清理
clean:
	rm -f $(OBJS) $(TARGET)

# 伪目标
.PHONY: clean
```

### 自动变量

| 变量 | 含义 |
|:----:|------|
| `$@` | 目标文件名 |
| `$<` | 第一个依赖文件名 |
| `$^` | 所有依赖文件 |
| `$?` | 所有比目标新的依赖文件 |
| `$*` | 不含后缀的目标名 |

## 第二部分：CMake

CMake是跨平台的构建系统，比Makefile更现代。

### CMakeLists.txt 示例

```cmake
cmake_minimum_required(VERSION 3.10)
project(MyApp VERSION 1.0)

# 设置C++标准
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 添加可执行文件
add_executable(myapp main.cpp foo.cpp bar.cpp)

# 添加头文件目录
target_include_directories(myapp PRIVATE include/)

# 链接库
target_link_libraries(myapp pthread dl)
```

### 构建步骤

```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
```

## 第三部分：GDB 调试器

### 编译时加调试信息

```bash
gcc -g program.c -o program
```

### 启动调试

```bash
gdb ./program
```

### GDB 常用命令速查

| 命令 | 简写 | 说明 |
|------|:----:|------|
| `break main` | `b main` | 在main函数设断点 |
| `break file.c:100` | `b file.c:100` | 在文件的第100行设断点 |
| `run` | `r` | 运行程序 |
| `next` | `n` | 单步执行（不进入函数）|
| `step` | `s` | 单步执行（进入函数）|
| `continue` | `c` | 继续执行到下一个断点 |
| `finish` | `fin` | 执行到当前函数返回 |
| `print x` | `p x` | 打印变量x的值 |
| `print *ptr` | `p *ptr` | 打印指针指向的内容 |
| `backtrace` | `bt` | 查看调用栈 |
| `frame 0` | `f 0` | 切换到栈帧0 |
| `info locals` | — | 查看局部变量 |
| `info break` | `i b` | 查看所有断点 |
| `delete 1` | `d 1` | 删除1号断点 |
| `watch x` | — | 监视变量x，变化时停止 |
| `list` | `l` | 显示当前行附近源代码 |
| `quit` | `q` | 退出 |

### 调试core dump

```bash
# 先设置core文件大小限制
ulimit -c unlimited

# 程序崩溃后
gdb ./program core
bt    # 查看崩溃时的调用栈
```

## 第四部分：Git 版本控制

### Git 工作区域

```
工作区(Working Directory) → 暂存区(Stage/Index) → 本地仓库(Repository) → 远程仓库(Remote)
     git add →          git commit →           git push →
```

### 基础命令

```bash
# 初始化/克隆
git init
git clone <url>

# 基本操作
git status                    # 查看状态
git add <file>                # 添加到暂存区
git add .                     # 添加所有修改
git commit -m "message"       # 提交到本地仓库
git push                      # 推送到远程
git pull                      # 拉取远程更新

# 分支操作
git branch <name>             # 创建分支
git checkout <name>           # 切换分支
git checkout -b <name>        # 创建并切换
git merge <name>              # 合并分支
git branch -d <name>          # 删除分支

# 查看历史
git log --oneline             # 简洁的提交历史
git log --graph               # 图形化分支历史
git diff                      # 查看工作区修改
git diff --cached             # 查看暂存区修改
```

### git reset vs git revert

| | git reset | git revert |
|:--|:----------|:-----------|
| 方式 | 回退到指定commit，丢弃之后的历史 | 生成新的commit来撤销指定commit |
| 历史 | 修改版本历史 | 保留版本历史 |
| 适用 | 本地未push的commit | 已push到远程的commit |

```bash
# reset 三种模式
git reset --soft <commit>    # 只移动HEAD，保留暂存区和工作区
git reset --mixed <commit>   # 移动HEAD，重置暂存区（默认）
git reset --hard <commit>    # 全部重置（危险！丢失修改）

# revert 安全撤销
git revert <commit>
```

### git stash（暂存修改）

```bash
git stash                    # 暂存当前修改
git stash pop                # 恢复最近一次暂存
git stash list               # 查看暂存列表
git stash apply stash@{0}    # 恢复指定暂存
git stash drop stash@{0}     # 删除指定暂存
```

**使用场景**：开发到一半需要切换分支，但不想commit，用stash暂存。

### git tag（标签）

```bash
git tag v1.0                  # 轻量标签
git tag -a v1.0 -m "描述"     # 附注标签
git push origin v1.0          # 推送标签
git push origin --tags        # 推送所有标签
```

### .gitignore 文件

```
# 忽略编译产物
*.o
*.exe
*.out
build/

# 忽略IDE文件
.vscode/
.idea/
*.swp

# 忽略系统文件
.DS_Store
Thumbs.db
```

### git rm 和 git mv

```bash
git rm <file>                  # 删除文件（从工作区和暂存区删除）
git rm --cached <file>         # 仅从暂存区移除跟踪，保留文件
git rm -r --cached .           # 清空暂存区（常用于重新整理.gitignore）
git mv <old> <new>             # 重命名文件
```

### checkout 的三个作用

1. **切换分支**：`git checkout <branch>`
2. **创建并切换**：`git checkout -b <newbranch>`
3. **恢复文件**：`git checkout -- <file>` 或 `git restore <file>`

### cherry-pick

```bash
git cherry-pick <commit>       # 将指定commit应用到当前分支
```

## 第五部分：Shell 脚本基础

### 特殊变量

| 变量 | 含义 |
|:----:|------|
| `$0` | 脚本名 |
| `$1-$9` | 位置参数 |
| `$#` | 参数个数 |

### 条件判断

```bash
if [ -f "file.txt" ]; then
    echo "文件存在"
elif [ -d "dir" ]; then
    echo "是目录"
else
    echo "不存在"
fi
```

for i in 1 2 3 4 5; do
