# 数据结构与算法完整指南


## 00-数据结构完整指南


> 数据结构是程序的骨架，算法是程序的灵魂。本篇涵盖从线性结构到高级树结构的完整知识体系。

## 第一章：数据结构入门

### 什么是数据结构

数据结构研究的是计算机中数据的**组织方式**和**操作方法**。程序 = 数据结构 + 算法。

### 数据结构三要素

1. **逻辑结构**：数据元素之间的逻辑关系
2. **存储结构**：数据在计算机中的存储方式（顺序/链式）
3. **运算**：对数据进行的操作（插入/删除/查找/排序）

## 第二章：线性表

### 线性表的特征

- 表头无前驱，表尾无后继
- 其他每个元素有且仅有一个直接前驱和一个直接后继

### 顺序表（数组实现）

优点：随机访问O(1)，存储密度高
缺点：插入/删除需要移动元素O(n)，需要连续内存空间

```c
// 顺序表结构
typedef struct {
    int *data;
    int length;
    int capacity;
} SeqList;
```

### 链表

**链式存储**：通过指针串联结点，每个结点包含数据域和指针域。

```c
// 单链表结点
typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 头插法
Node *headInsert(Node *head, int value) {
    Node *p = malloc(sizeof(Node));
    p->data = value;
    p->next = head;
    return p;  // 新头结点
}

// 尾插法
void tailInsert(Node **head, int value) {
    Node *p = malloc(sizeof(Node));
    p->data = value;
    p->next = NULL;
    if (*head == NULL) {
        *head = p;
        return;
    }
    Node *q = *head;
    while (q->next) q = q->next;
    q->next = p;
}

// 反转链表
Node *reverse(Node *head) {
    Node *prev = NULL, *curr = head, *next;
    while (curr) {
        next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

**链表操作可视化模型**：

```
顺序存储: [1][2][3][4][5]  连续内存

链式存储: [1|→] → [2|→] → [3|→] → [4|NULL]  不连续内存
```

## 第三章：栈与队列

### 栈（Stack）— LIFO

```c
// 顺序栈
typedef struct {
    int data[MAX_SIZE];
    int top;  // 栈顶指针
} Stack;

void push(Stack *s, int x) { s->data[++s->top] = x; }
int pop(Stack *s) { return s->data[s->top--]; }
int peek(Stack *s) { return s->data[s->top]; }
int isEmpty(Stack *s) { return s->top == -1; }
```

**应用场景**：函数调用栈、表达式求值、括号匹配、DFS

### 队列（Queue）— FIFO

```c
// 循环队列（避免假溢出）
typedef struct {
    int data[MAX_SIZE];
    int front;   // 队头
    int rear;    // 队尾
} Queue;

void enqueue(Queue *q, int x) {
    q->data[q->rear] = x;
    q->rear = (q->rear + 1) % MAX_SIZE;
}
int dequeue(Queue *q) {
    int x = q->data[q->front];
    q->front = (q->front + 1) % MAX_SIZE;
    return x;
}
```

**应用场景**：消息队列、BFS、打印机任务调度

### 特殊矩阵的压缩存储

- **对称矩阵**：只存上三角或下三角
- **三角矩阵**：存非零部分+一个常数

- **KMP算法**：O(n+m)，利用next数组避免回溯

## 第五章：二叉树

### 二叉树的性质

1. 第i层最多有 2^(i-1) 个结点
2. 深度为k的二叉树最多有 2^k - 1 个结点
3. n0 = n2 + 1（叶子结点数 = 度为2的结点数 + 1）

### 遍历方式

```
         A
       /   \
      B     C
     / \   / \
    D   E F   G

前序（根左右）: A B D E C F G
中序（左根右）: D B E A F C G
后序（左右根）: D E B F G C A
层次遍历:      A B C D E F G
```

```c
// 二叉树结点
typedef struct BtNode {
    int data;
    struct BtNode *leftChild;
    struct BtNode *rightChild;
} BtNode;

// 中序遍历（递归）
void inorder(BtNode *t) {
    if (t) {
        inorder(t->leftChild);
        printf("%d ", t->data);
        inorder(t->rightChild);
    }
}

// 前序遍历（非递归 - 用栈）
void preorder(BtNode *t) {
    Stack s; init(&s);
    BtNode *p = t;
    while (p || !isEmpty(&s)) {
        while (p) {
            printf("%d ", p->data);
            push(&s, p);
            p = p->leftChild;
        }
        p = pop(&s);
        p = p->rightChild;
    }
}
```

## 第六章：二叉搜索树（BST）

**性质**：左子树所有结点 < 根结点 < 右子树所有结点

```c
// 插入
BtNode *insert(BtNode *t, int x) {
    if (!t) {
        t = malloc(sizeof(BtNode));
        t->data = x;
        t->leftChild = t->rightChild = NULL;
        return t;
    }
    if (x < t->data)
        t->leftChild = insert(t->leftChild, x);
    else if (x > t->data)
        t->rightChild = insert(t->rightChild, x);
    return t;
}

// 查找
BtNode *search(BtNode *t, int key) {
    if (!t || t->data == key) return t;
    if (key < t->data)
        return search(t->leftChild, key);
    return search(t->rightChild, key);
}
```

**BST的问题**：最坏情况退化为链表（O(n)查找），引出平衡树。

## 第七章：线索二叉树

**目的**：利用二叉树的空指针域（n个结点有2n个指针域，n+1个是空的），存放前驱/后继信息。

```c
typedef struct TbtNode {
    int data;
    struct TbtNode *leftChild, *rightChild;
    int ltag, rtag;  // 0=指向孩子, 1=指向前驱/后继
} TbtNode;
```

**作用**：不借助栈/递归实现二叉树的遍历。

## 第八章：树、森林与二叉树的转换

**转换规则**：
- **树→二叉树**：左孩子右兄弟（每个结点左指针指向第一个孩子，右指针指向下一个兄弟）
- **森林→二叉树**：先将每棵树转换为二叉树，再将各二叉树的根用右指针连接

## 第九章：AVL树（平衡二叉搜索树）

**平衡因子**：左子树高度 - 右子树高度，AVL树要求 |平衡因子| ≤ 1

### 四种旋转

```
LL型（单右旋）:          RR型（单左旋）:
     A                       A
    /                       \
   B            →             B
  /                             \
 C                               C

LR型（先左后右）:        RL型（先右后左）:
     A                       A
    /                       \
   B            →             B
    \                       /
     C                     C
```

```c
// 获取高度
int height(AVLNode *t) {
    return t ? t->height : 0;
}

// 更新高度
void updateHeight(AVLNode *t) {
    t->height = max(height(t->left), height(t->right)) + 1;
}

// 左旋
AVLNode *leftRotate(AVLNode *t) {
    AVLNode *newRoot = t->right;
    t->right = newRoot->left;
    newRoot->left = t;
    updateHeight(t);
    updateHeight(newRoot);
    return newRoot;
}

// 右旋
AVLNode *rightRotate(AVLNode *t) {
    AVLNode *newRoot = t->left;
    t->left = newRoot->right;
    newRoot->right = t;
    updateHeight(t);
    updateHeight(newRoot);
    return newRoot;
}

// 带平衡的插入
AVLNode *insert(AVLNode *t, int x) {
    if (!t) { /* 创建新结点 */ return createNode(x); }

    if (x < t->data)
        t->left = insert(t->left, x);
    else if (x > t->data)
        t->right = insert(t->right, x);
    else return t;  // 不插入重复值

    updateHeight(t);
    int balance = height(t->left) - height(t->right);

    // LL
    if (balance > 1 && x < t->left->data) return rightRotate(t);
    // RR
    if (balance < -1 && x > t->right->data) return leftRotate(t);
    // LR
    if (balance > 1 && x > t->left->data) {
        t->left = leftRotate(t->left);
        return rightRotate(t);
    }
    // RL
    if (balance < -1 && x < t->right->data) {
        t->right = rightRotate(t->right);
        return leftRotate(t);
    }
    return t;
}
```

### AVL删除算法

删除比插入更复杂：删除后从被删除结点开始向上回溯调整平衡，可能需要多次旋转。

## 第十章：红黑树

### 五条性质

1. 每个结点不是红的就是黑的
2. 根结点为黑色
3. 红结点的孩子必为黑结点
4. 任一结点到叶子结点的所有路径上黑结点数量相同
5. 每个叶子结点（NIL）是黑色的

**记忆口诀**：一头一脚黑，黑同红不连

### AVL vs 红黑树

| 特性 | AVL树 | 红黑树 |
|------|:-----:|:-----:|
| 平衡性 | 严格平衡（高度差≤1）| 近似平衡 |
| 查找 | 更快（高度更低）| 稍慢 |
| 插入/删除 | 旋转次数可能较多 | 最多旋转2-3次 |
| 应用 | 查找密集型 | STL map/set（插入删除频繁）|

### 红黑树插入核心代码

```c
// 插入结点必须为红色（否则"黑同"被破坏）
void insertFixup(RBTree *t, Node *x) {
    Node *s;
    while (x->parent->color == RED) {
        if (x->parent == x->parent->parent->leftChild) {
            s = x->parent->parent->rightChild;  // 叔结点
            if (s->color == RED) {
                // 情况1：叔为红 → 变色
                x->parent->color = BLACK;
                s->color = BLACK;
                x->parent->parent->color = RED;
                x = x->parent->parent;
                continue;
            } else if (x == x->parent->rightChild) {
                // 情况2：LR → 左旋
                x = x->parent;
                leftRotate(t, x);
            }
            // 情况3：LL → 右旋+变色
            x->parent->color = BLACK;
            x->parent->parent->color = RED;
            rightRotate(t, x->parent->parent);
        } else {
            // 右边镜像操作...
        }
    }
    t->root->color = BLACK;  // 根始终为黑
}
```

## 第十一章：堆

### 堆的定义

堆是一种**完全二叉树**的线性表示（数组存储）：

- **大堆**：父结点 ≥ 左右孩子 → 降序
- **小堆**：父结点 ≤ 左右孩子 → 升序

### 小堆实现

```cpp
// 向下调整（构建小堆的核心）
void siftDown(int start, int end) {
    int i = start;      // 父结点
    int j = 2*i + 1;    // 左孩子
    Type tmp = heap[i];

    while (j <= end) {
        if (j+1 <= end && heap[j] > heap[j+1])
            j = j+1;    // 选较小的孩子
        if (tmp > heap[j]) {
            heap[i] = heap[j];  // 孩子上移
        } else break;
        i = j;
        j = 2*i + 1;
    }
    heap[i] = tmp;
}

// 向上调整（插入时用）
void siftUp(int start) {
    int j = start;
    int i = (j-1)/2;  // 父结点位置
    Type tmp = heap[j];
    while (j > 0) {
        if (heap[i] > tmp) {
            heap[j] = heap[i];
        } else break;
        j = i;
        i = (j-1)/2;
    }
    heap[j] = tmp;
}

// 删除堆顶（得到最小值）
bool remove(Type &v) {
    if (size == 0) return false;
    v = heap[0];
    heap[0] = heap[size-1];
    size--;
    siftDown(0, size-1);
    return true;
}

// 堆排序：反复remove堆顶得到有序序列
for (int i = 0; i < n; i++) {
    hp.remove(value);
    cout << value << " ";  // 升序输出
}
```

**堆的应用**：优先队列、Top-K问题、堆排序（O(n log n)）

## 第十二章：哈希表

### 核心概念

哈希表 = 哈希函数 + 解决冲突

通过哈希函数将key映射到数组下标，实现O(1)的查找。

### 哈希函数构造方法

| 方法 | 说明 |
|------|------|
| 直接定址法 | H(key) = key（空间浪费大）|
| 除留余数法 | H(key) = key % p（最常用，p取质数）|
| 数字分析法 | 取key中分布均匀的几位 |
| 平方取中法 | 取key²的中间几位 |

**除留余数法是最常用的**，p取质数保证均匀分布。

### 冲突解决方法

| 方法 | 做法 | 优缺点 |
|------|------|--------|
| 线性探测 | 冲突后顺次往后找空位 | 简单，但容易聚集 |
| 二次探测 | 冲突后左右跳跃找空位 | 减少聚集 |
| 双散列 | 两个哈希函数配合 | 精度高 |
| **链地址法** | 每个槽存链表头指针 | **最常用** |

### 链地址法完整实现

```c
#define P 7  // 质数

typedef struct HASH_NODE {
    int data;
    struct HASH_NODE *next;
} HASH_NODE;

typedef HASH_NODE *HashTable[P];  // 指针数组

int Hash(int key) { return key % P; }

void initHashTable(HashTable ht) {
    for (int i = 0; i < P; i++)
        ht[i] = NULL;
}

// 头插法（O(1)）
void prevInsert(HashTable ht, int value) {
    int index = Hash(value);
    HASH_NODE *p = malloc(sizeof(HASH_NODE));
    p->data = value;
    p->next = ht[index];
    ht[index] = p;
}

// 哈希查找
HASH_NODE *find(HashTable ht, int value) {
    int index = Hash(value);
    HASH_NODE *p = ht[index];
    while (p && p->data != value)
        p = p->next;
    return p;  // 返回NULL表示未找到
}

// 哈希删除
bool remove_(HashTable ht, int value) {
    int index = Hash(value);
    HASH_NODE *p = find(ht, value);
    if (!p) return false;

    HASH_NODE *q = ht[index];
    if (ht[index] == p) {
        ht[index] = p->next;  // 是第一个结点
    } else {
        while (q->next != p) q = q->next;
        q->next = p->next;
    }
    free(p);
    return true;
}

// 销毁哈希表
void destroyHashTable(HashTable ht) {
    for (int i = 0; i < P; i++) {
        HASH_NODE *p = ht[i];
        while (p) {
            HASH_NODE *q = p->next;
            free(p);
            p = q;
        }
        ht[i] = NULL;
    }
}
```

## 第十四章：图

### 图的存储

**邻接矩阵**：

```c
// 适合稠密图，O(n²)空间
int matrix[MAX_V][MAX_V];
```

**邻接表**：

```c
// 适合稀疏图，O(n+e)空间
typedef struct Edge {
    int dest;           // 目标顶点
    struct Edge *next;  // 下一条边
} Edge;

typedef struct Vertex {
    int data;
    Edge *adj;   // 邻接边链表
} Vertex;
```

### 图的遍历

**DFS（深度优先）**：

```c
void DFS(Graph *g, int v) {
    visited[v] = 1;
    printf("%d ", v);
    // 遍历v的所有邻接点
    int w = getFirstNeighbor(g, v);
    while (w != -1) {
        if (!visited[w])
            DFS(g, w);
        w = getNextNeighbor(g, v, w);
    }
}
```

**BFS（广度优先）**：使用队列，逐层访问。

**非连通图遍历**：用一个`components()`函数遍历所有顶点，对每个未访问的顶点调用DFS/BFS。
