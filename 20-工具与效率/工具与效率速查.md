## 00-工具与效率速查

## ⌨️ Vim 快捷键

### 代码对齐

```bash
==       # 格式化对齐当前行（4== 对齐当前行+后面3行）
gg=G     # 整个文件格式化对齐
```

### 文件分屏

```bash
:vsp 文件名    # 垂直分屏打开文件
:sp 文件名     # 水平分屏打开文件
Ctrl+w h/j/k/l # 在分屏间切换
```

### 批量替换

```bash
:%s/old/new/g     # 替换整个文件的匹配
:%s/old/new/gc    # 替换前逐个确认
```

### SSH 远程开发

**免密登录配置：**

```bash
# 1. Windows 生成密钥
ssh-keygen -t rsa -b 4096

# 2. 复制公钥到远程服务器
# 将 C:\Users\用户名\.ssh\id_rsa.pub 内容追加到
# 远程服务器的 ~/.ssh/authorized_keys
```

**SSH Config 示例：**

```
Host myserver
  HostName 192.168.x.x
  User yxy
  IdentityFile c:/Users/用户名/.ssh/id_rsa
```

## 🐧 Linux 常用命令速查

### 进程相关

```bash
ps -eLf | grep 进程名    # 查看所有线程
# 输出: 用户 PID PPID 线程ID CPU 状态 时间 终端 运行时间 命令
```

### 文本处理

```bash
wc -l file.txt      # 行数
wc -w file.txt      # 字数
wc -c file.txt      # 字节数
wc -L file.txt      # 最长行长度

grep -r "文本" 目录  # 递归搜索文本
locate 文件名        # 快速定位文件
```

### 用户与权限

```bash
su -l 用户名    # 完整切换用户（重置环境变量）
su 用户名       # 仅切换用户身份
passwd          # 修改密码

ln -s 源 目标   # 创建软链接
ln 源 目标      # 创建硬链接
```

### Shell 计算与管道

```bash
let a=5+4       # 变量计算
echo "2+4" | bc # 管道计算
alias ll='ls -alF'  # 设置别名
```

## 🔗 符号类型速查（ELF）

| 类型 | 含义 |
|:----:|------|
| T | 代码段全局符号 |
| t | 代码段局部符号 |
| D | 数据段全局符号 |
| d | 数据段局部符号 |
| B | BSS段全局符号 |
| b | BSS段局部符号 |
| R | 只读数据段全局符号 |
| r | 只读数据段局部符号 |
| U | 未定义（外部引用）|

### ELF 分析命令

```bash
readelf -d a.out      # 查看动态链接库
readelf -h a.out      # ELF头信息
readelf -s a.out      # 符号表
nm -C -n -l a.out     # 列出符号
patchelf --set-rpath /path my-program  # 修改RPATH
ldd a.out             # 查看动态库依赖
```
